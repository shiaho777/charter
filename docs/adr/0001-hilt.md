# ADR 0001: Hilt 而不是 Koin

- 状态：Accepted
- 日期：2026-09-07

## 背景

DI 容器是"规范性"人设的一部分。候选：Hilt（Dagger）与 Koin。

## 决定

用 **Hilt**。依赖图在编译期校验，错依赖直接编译失败——这与项目"规范能机器化就机器化"的原则同构。Koin 的运行时解析把错误推迟到运行期，与原则相悖。

## 代价与对策

- KSP 增加构建耗时：用 convention plugin 统一开关，feature 模板默认带上。
- 测试替换：`core:testing` 提供 fake 实现，ViewModel 单测不启动 Hilt。
- KMP 不兼容：本项目定位为纯 Android（见 ADR 0004），此代价接受。

## 推翻条件

项目转向 Compose Multiplatform 时，重新评估 Koin 或 kotlin-inject。
