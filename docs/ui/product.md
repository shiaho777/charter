# 产品设计哲学

功能设计范式总纲。UI 层面的品味见
[taste.md](taste.md)；这里管的是**功能怎么想**。

## 1. Onboarding 是配置收集器，不是欢迎轮播

首次启动要解决的唯一问题：**用户在使用核心功能前必须做的决定**。
每一步都对应一个"不决定就会失败"的场景，没有为了好看而存在的步骤。

典型四步拆解：
1. 使用约定 → 法律合规前置（采集类工具的边界）
2. 更新来源 → 弱网用户可能连不上默认源
3. 网络镜像 → 同上，且文案写明"中国大陆用户推荐启用"（场景感知）
4. 核心功能依赖 → 不配置就空转的东西，且**内置默认值兜底**：
   同意时才安装内置规则，失败 toast 但不阻塞进入 app——首启路径是
   渐进增强的，不是全有或全无的。

**检测**：删掉 onboarding 的任何一步，用户会在哪里第一次撞墙？
答不上来的步骤就是装饰，删掉。

## 2. 错误是人话，面向下一步行动

用户不需要知道底层报了什么，用户需要知道**下一步做什么**。

```
底层: "Failed to recognize file format"
错误: "加载失败，请尝试更换其他视频来源"   ← 告诉用户能做什么
```

规则：
- 错误文案 = 现象 + 可行动的下一步（"请尝试 X"），不是技术描述。
- 错误映射是一个专门的、穷举的翻译层（PlayerErrorMapper
  模式）：底层异常 → 用户话术，不认识的原样走默认——不硬翻译。
- Charter 的对应：`AppError` 分类是穷举的，但 UI 文案映射也必须
  每类都有"下一步"话术，不允许裸展示 `error.message`。

## 3. In-flight 状态是行级的，不是全页的

一个列表里 10 个操作在飞，就 10 个行各自显示自己的进行中状态。
全页 spinner 只在"整个数据源在加载"时出现。

典型拆解（历史记录删除）：
- `Set<key> deleting` 跟踪每行的 in-flight，行级置灰/禁点。
- 删除成功 → 行消失；失败 → toast + **行保留**（数据没变，UI 不该变）。
- 批量操作（清空）与单操作互斥（`_clearing || _deleting.isNotEmpty`
  时互相拒绝）——防竞态的简单实现。
- 删完最后一行自动退出编辑模式——**操作完成后 UI 状态自动收敛**，
  不需要用户手动刷新。

## 4. 破坏性确认不打断流程

退出确认用 toast（"再按一次退出应用"，2 秒窗口），不是模态对话框。
第一次返回 = 回首页 tab，第二次 = 退出。

规则：
- 能用非模态（toast + 时间窗）防误触的，不上模态。
- 真正模态确认只留给**不可逆**且**影响面大**的操作（清空全部数据）。
- 给反悔的机会 ≠ 强迫用户做决定。

## 5. 设置是声明式目录，不是代码迷宫

设置页的结构是**数据**：`List<SettingsGroup>` 里每个条目有
id / label / 一句话说明 / icon / builder。加一个设置分类 = 加一条
数据，渲染逻辑一个 `SettingsList` 通吃。

规则：
- 每个设置条目必须有一句话说明（用户不需要点进去才知道这是什么）。
- 按领域分组（播放 / 网络 / 存储…），不按实现分类。
- 设置项的存储 key 和默认值集中在契约里，不散落在 widget。

## 6. 巨石控制器拆成关注点切片

播放器有播放/面板/seek/弹幕/同步/调试/超分七个关注点，每个是独立的
子控制器；对外组合成一个门面。子控制器间引用兄弟状态用函数式 getter
（`() => videoUrl`），避免初始化顺序依赖。

规则：
- 一个"屏幕"的控制器超过一个关注点，就按动词拆（playback/seek/panel…）。
- 跨切片读状态用 lambda，不用构造期快照。
- 对 View 暴露单一门面。

## 7. 数据的时间维度完整暴露

时间表不是只有"本周"，是 20 年的季选择器——"2015 年冬有什么"是合法
需求。评分显示是可关的——信息密度可配置。

规则：
- 列表/时间线类数据默认提供完整的时间导航，不人为截断"最近"。
- 高密度辅助信息（评分、元数据）默认展示，允许一键降密。

## 8. 平台差异是数据，不是 if-else 森林

onboarding 步骤里 `if (Platform.isAndroid) updates`——平台差异
在数据组装层解决一次，渲染层无感知。

规则：
- 平台/渠道/配置的差异收敛到"构建步骤列表"的那一处。
- 渲染层不知道差异存在。
